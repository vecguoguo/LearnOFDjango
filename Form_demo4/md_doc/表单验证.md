# 表单验证

## 一、常用的 Field：

使用 `Field` 可以是对数据验证的第一步。你期望这个提交上来的数据是什么类型，那么就使用什么类型的 `Field`。

### 1. CharField：

用来接收文本。
参数：

- `max_length`：这个字段值的最大长度。
- `min_length`：这个字段值的最小长度。
- `required`：这个字段是否是必须的。默认是必须的。
- `error_messages`：在某个条件验证失败的时候，给出错误信息。

### 2. EmailField：

用来接收邮件，会自动验证邮件是否合法。
错误信息的 key：`required`、`invalid`。

### 3. FloatField：

用来接收浮点类型，如果验证的数据不是一个浮点类型，那么会验证失败。
错误信息的 key：`required`、`invalid`。
参数：

- `max_value`：最大的值。
- `min_value`：最小的值。

### 4. IntegerField：

用来接收整型，如果验证的数据不是一个整型，那么会验证失败。
错误信息的 key：`required`、`invalid`。
参数：

- `max_value`：最大的值。
- `min_value`：最小的值。

### 5. URLField：

用来接收 URL 格式的字符串，会自动验证 URL 是否合法。
错误信息的 key：`required`、`invalid`。

### 6. BooleanField：

用来接收布尔值（`True` 或 `False`）。
参数：

- `required`：这个字段是否是必须的。默认是必须的。

### 7. ChoiceField：

用来接收下拉框的数据。
参数：

- `choices`：一个包含二元组（`(value, display_name)`）的列表或元组，用来指定可选的选项。

### 8. FileField 和 ImageField：

用来接收上传的文件和图片。其中 `ImageField` 会自动验证上传的是否为真实的图片。

## 二、常用的验证器：

在验证某个字段的时候，可以传递一个 `validators` 参数用来指定验证器，进一步对数据进行过滤。验证器有很多，但是很多验证器我们其实已经通过 `Field` 或者一些参数就可以指定了。比如 `EmailValidator`，我们可以通过 `EmailField` 来指定，比如 `MaxValueValidator`，我们可以通过 `max_value` 参数来指定。以下是一些常用的验证器：

### 1. MaxValueValidator：

验证最大值。示例代码如下：

```python
from django import forms
from django.core import validators

class MyForm(forms.Form):
    age = forms.IntegerField(validators=[validators.MaxValueValidator(100)])
```

### 2. MinValueValidator：

验证最小值。示例代码如下：

```python
from django import forms
from django.core import validators

class MyForm(forms.Form):
    age = forms.IntegerField(validators=[validators.MinValueValidator(18)])
```

### 3. MaxLengthValidator：

验证最大长度。示例代码如下：

```python
from django import forms
from django.core import validators

class MyForm(forms.Form):
    username = forms.CharField(validators=[validators.MaxLengthValidator(10)])
```

### 4. MinLengthValidator：

验证最小长度。示例代码如下：

```python
from django import forms
from django.core import validators

class MyForm(forms.Form):
    username = forms.CharField(validators=[validators.MinLengthValidator(3)])
```

### 5. EmailValidator：

验证邮箱格式。示例代码如下：

```python
from django import forms
from django.core import validators

class MyForm(forms.Form):
    email = forms.CharField(validators=[validators.EmailValidator()])
```

### 6. RegexValidator：

正则表达式验证器。示例代码如下：

```python
from django import forms
from django.core import validators

class MyForm(forms.Form):
    phone = forms.CharField(validators=[
        validators.RegexValidator(r'^1[3-9]\d{9}$', message='手机号格式不正确')
    ])
```

## 三、自定义验证器：

有时候 Django 内置的验证器不能满足需求，可以自定义验证器。自定义验证器本质上就是一个函数，接收一个值作为参数，如果验证失败，抛出 `ValidationError` 异常。

```python
from django.core.exceptions import ValidationError

def validate_even(value):
    if value % 2 != 0:
        raise ValidationError('%(value)s 不是一个偶数', params={'value': value})
```

然后在 `Field` 中使用：

```python
from django import forms

class MyForm(forms.Form):
    num = forms.IntegerField(validators=[validate_even])
```

## 四、表单的验证流程：

1. 调用 `form.is_valid()` 方法触发验证。
2. 如果所有字段都验证通过，`is_valid()` 返回 `True`，验证后的数据保存在 `form.cleaned_data` 字典里。
3. 如果验证失败，`is_valid()` 返回 `False`，错误信息保存在 `form.errors` 里，可以在模板中展示。

```python
def my_view(request):
    if request.method == 'POST':
        form = MyForm(request.POST)
        if form.is_valid():
            # 验证通过，处理数据
            email = form.cleaned_data['email']
            # ... 业务逻辑
        else:
            # 验证失败，打印错误信息
            print(form.errors)
    else:
        form = MyForm()
    return render(request, 'my_template.html', {'form': form})
```

## 五、总结：

| Field 类型 | 用途 |
|------------|------|
| `CharField` | 接收文本 |
| `EmailField` | 接收邮箱，自动校验格式 |
| `FloatField` | 接收浮点数 |
| `IntegerField` | 接收整数 |
| `URLField` | 接收 URL，自动校验格式 |

| 验证器 | 作用 |
|--------|------|
| `MaxValueValidator` | 验证最大值 |
| `MinValueValidator` | 验证最小值 |
| `MaxLengthValidator` | 验证最大长度 |
| `MinLengthValidator` | 验证最小长度 |
| `EmailValidator` | 验证邮箱 |
| `RegexValidator` | 正则验证 |

- 验证失败会抛出 `ValidationError`。
- 使用 `validators=[...]` 参数可以给字段添加验证器。
- 也可以自定义验证器，本质是一个抛出 `ValidationError` 的函数。
- 表单验证通过后，数据在 `form.cleaned_data` 中。
