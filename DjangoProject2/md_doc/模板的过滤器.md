Django 模板过滤器用于在模板中**对变量进行格式化或转换**，语法是 `{{ 变量|过滤器 }}`。下面按用途分类介绍常用过滤器，并给出一个完整的小示例。

### 一、常用过滤器分类

#### 1. 字符串处理

| 过滤器 | 作用 | 示例 |
|--------|------|------|
| `lower` | 转小写 | `{{ "ABC"|lower }}` → `abc` |
| `upper` | 转大写 | `{{ "abc"|upper }}` → `ABC` |
| `title` | 每个单词首字母大写 | `{{ "hello world"|title }}` → `Hello World` |
| `capfirst` | 首字母大写 | `{{ "hello"|capfirst }}` → `Hello` |
| `truncatechars` | 截断字符，超出加 `...` | `{{ "这是一段很长的文字"|truncatechars:5 }}` |
| `truncatewords` | 截断单词 | `{{ "one two three"|truncatewords:2 }}` → `one two ...` |
| `length` | 返回长度 | `{{ "hello"|length }}` → `5` |
| `default` | 变量为空时用默认值 | `{{ name|default:"匿名" }}` |
| `default_if_none` | 仅当值为 None 时用默认值 | `{{ name|default_if_none:"空" }}` |
| `cut` | 删除指定字符 | `{{ "a-b-c"|cut:"-" }}` → `abc` |
| `join` | 用指定字符连接列表 | `{{ list|join:", " }}` |

#### 2. 数字处理

| 过滤器 | 作用 | 示例 |
|--------|------|------|
| `add` | 加法 | `{{ 5|add:3 }}` → `8` |
| `divisibleby` | 能否整除 | `{{ 9|divisibleby:3 }}` → `True` |
| `floatformat` | 保留小数位 | `{{ 3.14159|floatformat:2 }}` → `3.14` |

#### 3. 日期时间

| 过滤器 | 作用 | 示例 |
|--------|------|------|
| `date` | 格式化日期 | `{{ now|date:"Y-m-d" }}` → `2026-10-13` |
| `time` | 格式化时间 | `{{ now|time:"H:i" }}` |
| `timesince` | 距现在多久 | `{{ past|timesince }}` → `3 days` |

#### 4. 列表与字典

| 过滤器 | 作用 | 示例 |
|--------|------|------|
| `first` | 第一个元素 | `{{ list|first }}` |
| `last` | 最后一个元素 | `{{ list|last }}` |
| `slice` | 切片 | `{{ list|slice:":3" }}` |
| `dictsort` | 按指定字段给字典列表排序 | `{{ users|dictsort:"age" }}` |

#### 5. 安全与转义

| 过滤器 | 作用 | 示例 |
|--------|------|------|
| `safe` | 标记为安全，不转义 HTML | `{{ content|safe }}` |
| `escape` | 转义 HTML | `{{ "<b>"|escape }}` → `&lt;b&gt;` |
| `striptags` | 去掉 HTML 标签 | `{{ "<p>hi</p>"|striptags }}` → `hi` |

### 二、完整小示例

下面做一个简单的“用户信息展示页”，演示多个过滤器的实际效果。

#### 1. 视图 `views.py`

```python
from django.shortcuts import render
from datetime import datetime, timedelta

def user_profile(request):
    context = {
        'username': '  zhangsan  ',
        'bio': '这是一个非常非常长的个人简介，需要被截断显示。',
        'age': 25,
        'price': 1234.5678,
        'join_date': datetime(2024, 3, 15),
        'last_login': datetime.now() - timedelta(hours=3),
        'hobbies': ['篮球', '阅读', '编程'],
        'score': 88,
        'email': '',
    }
    return render(request, 'profile.html', context)
```

#### 2. 模板 `profile.html`

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>用户信息</title>
</head>
<body>
    <h1>用户信息</h1>

    <!-- 字符串处理 -->
    <p>用户名：{{ username|cut:" "|capfirst }}</p>
    <p>简介：{{ bio|truncatechars:15 }}</p>

    <!-- 数字处理 -->
    <p>年龄：{{ age }}</p>
    <p>价格：{{ price|floatformat:2 }}</p>
    <p>加分后年龄：{{ age|add:5 }}</p>

    <!-- 日期处理 -->
    <p>注册日期：{{ join_date|date:"Y年m月d日" }}</p>
    <p>最后登录：{{ last_login|timesince }} 前</p>

    <!-- 列表处理 -->
    <p>爱好数量：{{ hobbies|length }}</p>
    <p>第一个爱好：{{ hobbies|first }}</p>
    <p>爱好列表：{{ hobbies|join:"、" }}</p>

    <!-- 默认值 -->
    <p>邮箱：{{ email|default:"未填写" }}</p>

    <!-- 条件判断结合过滤器 -->
    {% if score|divisibleby:2 %}
        <p>分数是偶数</p>
    {% else %}
        <p>分数是奇数</p>
    {% endif %}
</body>
</html>
```

#### 3. 路由 `urls.py`

```python
from django.urls import path
from . import views

urlpatterns = [
    path('profile/', views.user_profile, name='profile'),
]
```

### 三、补充说明

- **过滤器可以链式调用**：`{{ name|lower|capfirst }}`，先转小写再首字母大写。
- **带参数的过滤器**用冒号：`{{ bio|truncatechars:15 }}`。
- **自定义过滤器**：在 app 下建 `templatetags` 目录，写 `my_filters.py`，用 `@register.filter` 注册，然后在模板里 `{% load my_filters %}` 使用。
- **`safe` 要慎用**：它会让 HTML 不被转义，如果内容来自用户输入，可能引发 XSS 攻击。
