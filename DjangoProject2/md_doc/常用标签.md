Django 模板标签很多，但日常开发中最常用的其实就下面这些。我按使用频率列出来，并配上例子。

### 一、最常用的模板标签

| 标签 | 用途 |
|------|------|
| `{% if %}` | 条件判断 |
| `{% for %}` | 循环遍历 |
| `{% url %}` | 反向解析 URL |
| `{% static %}` | 引用静态文件 |
| `{% extends %}` | 继承父模板 |
| `{% block %}` | 定义可覆盖的块 |
| `{% include %}` | 包含子模板 |
| `{% csrf_token %}` | 表单 CSRF 令牌 |
| `{% load %}` | 加载自定义标签库 |
| `{% with %}` | 给变量起别名 |
| `{% comment %}` | 多行注释 |
| `{% now %}` | 当前日期时间 |

### 二、具体例子

#### 1. `{% if %}` 条件判断

```django
{% if user.is_authenticated %}
    <p>欢迎回来，{{ user.username }}</p>
{% elif user.is_staff %}
    <p>管理员你好</p>
{% else %}
    <p>请先登录</p>
{% endif %}
```
在for循环中添加`reversed`可以反转列表

支持 `and`、`or`、`not`、`in`、`==` 等运算符：

```django
{% if age >= 18 and city == "北京" %}
    <p>可以参加</p>
{% endif %}
```

#### 2. `{% for %}` 循环

```django
<ul>
{% for article in article_list %}
    <li>{{ forloop.counter }}. {{ article.title }}</li>
{% empty %}
    <li>暂无文章</li>
{% endfor %}
</ul>
```

`forloop` 常用变量：
- `forloop.counter`：当前第几次（从 1 开始）
- `forloop.counter0`：从 0 开始
- `forloop.first`：是否第一次循环
- `forloop.last`：是否最后一次循环

```django
{% for item in items %}
    {% if forloop.first %}<hr>{% endif %}
    <p>{{ item }}</p>
{% endfor %}
```

#### 3. `{% url %}` 反向解析

```django
<a href="{% url 'article_detail' article.id %}">阅读全文</a>
```

对应 `urls.py`：

```python
path('article/<int:id>/', views.article_detail, name='article_detail')
```

如果 URL 带命名空间：

```django
{% url 'blog:article_detail' article.id %}
```

#### 4. `{% static %}` 静态文件

```django
{% load static %}
<link rel="stylesheet" href="{% static 'css/style.css' %}">
<img src="{% static 'images/logo.png' %}" alt="logo">
```

#### 5. `{% extends %}` + `{% block %}` 模板继承

父模板 `base.html`：

```django
<!DOCTYPE html>
<html>
<head>
    <title>{% block title %}我的网站{% endblock %}</title>
</head>
<body>
    <header>导航栏</header>
    {% block content %}{% endblock %}
    <footer>页脚</footer>
</body>
</html>
```

子模板 `article.html`：

```django
{% extends "base.html" %}

{% block title %}文章详情{% endblock %}

{% block content %}
    <h1>{{ article.title }}</h1>
    <p>{{ article.body }}</p>
{% endblock %}
```

注意：`{% extends %}` 必须是子模板第一行。

#### 6. `{% include %}` 包含子模板

```django
{% include "partials/navbar.html" %}

{# 可以传参 #}
{% include "partials/card.html" with title="最新文章" %}
```

#### 7. `{% csrf_token %}` 表单令牌

```django
<form method="post">
    {% csrf_token %}
    <input type="text" name="username">
    <button type="submit">提交</button>
</form>
```

只要是 POST 表单，就必须加这个标签，否则会报 403。

#### 8. `{% with %}` 起别名

```django
{% with total=article.comments.count %}
    <p>共 {{ total }} 条评论</p>
{% endwith %}
```

适合变量名太长或需要重复调用方法时。

#### 9. `{% comment %}` 注释

```django
{% comment %}
    这段内容不会显示
    可以写多行
{% endcomment %}
```

单行注释用 `{# 这是注释 #}`。

#### 10. `{% now %}` 当前时间

```django
<p>现在是 {% now "Y年m月d日 H:i" %}</p>
```

#### 11. `{% load %}` 加载自定义标签

```django
{% load static %}
{% load my_filters %}
```

### 三、组合示例：一个文章列表页

```django
{% extends "base.html" %}
{% load static %}

{% block title %}文章列表{% endblock %}

{% block content %}
    <h1>文章列表</h1>

    {% if article_list %}
        <ul>
        {% for article in article_list %}
            <li>
                <a href="{% url 'article_detail' article.id %}">
                    {{ article.title }}
                </a>
                <span>{% now "Y-m-d" %}</span>
                {% if forloop.last %}<em>（最后一条）</em>{% endif %}
            </li>
        {% endfor %}
        </ul>
    {% else %}
        <p>暂无文章</p>
    {% endif %}
{% endblock %}
```

这个例子用到了 `extends`、`load`、`block`、`if`、`for`、`url`、`now` 等多个常用标签，基本覆盖了日常开发的大部分场景。
