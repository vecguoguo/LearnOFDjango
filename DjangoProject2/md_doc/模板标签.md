Django 模板标签是模板语言的核心组成部分，用于在模板中实现逻辑控制、循环、继承等功能。以下是常用的模板标签分类整理：

### 一、核心逻辑标签

| 标签 | 说明 |
|------|------|
| `{% if %}` / `{% elif %}` / `{% else %}` / `{% endif %}` | 条件判断 |
| `{% for %}` / `{% empty %}` / `{% endfor %}` | 循环遍历，`empty` 处理空列表 |
| `{% comment %}` / `{% endcomment %}` | 多行注释 |
| `{# ... #}` | 单行注释 |

### 二、模板继承与复用

| 标签 | 说明 |
|------|------|
| `{% extends "base.html" %}` | 继承父模板，必须放在模板第一行 |
| `{% block name %}` / `{% endblock %}` | 定义可被子模板覆盖的块 |
| `{% include "xxx.html" %}` | 包含另一个模板 |
| `{% ssi %}` | 服务端包含（需配置，较少用） |

### 三、变量与赋值

| 标签 | 说明 |
|------|------|
| `{% load %}` | 加载自定义标签库或过滤器 |
| `{% with %}` / `{% endwith %}` | 在块内给变量起别名 |
| `{% csrf_token %}` | 生成 CSRF 令牌，用于表单 |
| `{% autoescape %}` / `{% endautoescape %}` | 控制自动转义 |

### 四、URL 与静态文件

| 标签 | 说明 |
|------|------|
| `{% url 'name' arg1 arg2 %}` | 根据 URL 名称反向解析地址 |
| `{% static 'path/to/file' %}` | 引用静态文件 |
| `{% get_static_prefix %}` | 获取静态文件前缀 |
| `{% get_media_prefix %}` | 获取媒体文件前缀 |

### 五、国际化与本地化

| 标签 | 说明 |
|------|------|
| `{% trans "text" %}` | 翻译字符串 |
| `{% blocktrans %}` / `{% endblocktrans %}` | 翻译含变量的块 |
| `{% get_current_language %}` | 获取当前语言 |
| `{% get_available_languages %}` | 获取可用语言列表 |

### 六、其他常用标签

| 标签 | 说明 |
|------|------|
| `{% now "Y-m-d" %}` | 输出当前日期时间 |
| `{% templatetag %}` | 输出模板标签的原始字符 |
| `{% verbatim %}` / `{% endverbatim %}` | 原样输出，不解析模板语法 |
| `{% cycle %}` | 循环输出一组值 |
| `{% firstof %}` | 输出第一个为真的变量 |
| `{% ifchanged %}` | 检测值是否变化 |
| `{% regroup %}` | 按属性分组列表 |
| `{% widthratio %}` | 计算比例 |
| `{% lorem %}` | 生成占位文本 |
| `{% debug %}` | 输出调试信息 |
| `{% filter %}` | 对块内容应用过滤器 |
| `{% spaceless %}` | 去除标签间空白 |

### 七、自定义标签
通过 `{% load %}` 加载自定义标签库后使用，需在 `templatetags/` 目录下创建模块并用 `@register.simple_tag` 或 `@register.inclusion_tag` 注册。

### 八、注意事项
- `{% for %}` 循环中可用 `forloop.counter`、`forloop.first`、`forloop.last` 等变量。
- `{% if %}` 支持 `and`、`or`、`not`、`in`、`==`、`!=`、`<`、`>` 等运算符。
- 大部分标签需要成对出现（如 `if`/`endif`），自闭合标签（如 `{% url %}`、`{% static %}`）不需要。
