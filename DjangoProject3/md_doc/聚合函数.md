# 二、聚合函数：

如果你用原生 SQL，则可以使用聚合函数来提取数据。比如提取某个商品销售的数量，那么可以使用 `Count`，如果想要知道商品销售的平均价格，那么可以使用 `Avg`。
聚合函数是通过 `aggregate` 方法来实现的。在讲解这些聚合函数的用法的时候，都是基于以下的模型对象来实现的。

```python
from django.db import models

class Author(models.Model):
    """作者模型"""
    name = models.CharField(max_length=100)
    age = models.IntegerField()
    email = models.EmailField()

    class Meta:
        db_table = 'author'


class Publisher(models.Model):
    """出版社模型"""
    name = models.CharField(max_length=300)

    class Meta:
        db_table = 'publisher'


class Book(models.Model):
    """图书模型"""
    name = models.CharField(max_length=300)
    pages = models.IntegerField()
    price = models.FloatField()
    rating = models.FloatField()
    author = models.ForeignKey(Author, on_delete=models.CASCADE)
    publisher = models.ForeignKey(Publisher, on_delete=models.CASCADE)

    class Meta:
        db_table = 'book'


class BookOrder(models.Model):
    """图书订单模型"""
    book = models.ForeignKey(Book, on_delete=models.CASCADE)
    price = models.FloatField()

    class Meta:
        db_table = 'book_order'
```

## 1. `aggregate` 和 `annotate` 的区别

在讲聚合函数之前，先区分两个方法：

*   **`aggregate`**：作用于整个 `QuerySet`，返回一个字典，字典的 key 是聚合函数的别名，value 是计算结果。比如计算所有图书的平均价格。
*   **`annotate`**：作用于 `QuerySet` 中的每一行，为每一行添加一个聚合结果作为属性。比如给每个作者添加一个“图书数量”字段。

简单记：**`aggregate` 是整体汇总，`annotate` 是逐行附加**。

## 2. `Avg`：求平均值

求所有图书的平均价格：

```python
from django.db.models import Avg

result = Book.objects.aggregate(Avg('price'))
print(result)
# 输出：{'price__avg': 50.0}
```

可以自定义返回的 key 名：

```python
result = Book.objects.aggregate(avg_price=Avg('price'))
print(result)
# 输出：{'avg_price': 50.0}
```

## 3. `Count`：求数量

求图书的总数量：

```python
from django.db.models import Count

result = Book.objects.aggregate(Count('id'))
print(result)
# 输出：{'id__count': 10}
```

如果想统计不重复的值，可以加 `distinct=True`：

```python
result = Book.objects.aggregate(Count('author', distinct=True))
```

## 4. `Max`：求最大值

求所有图书中最高的价格：

```python
from django.db.models import Max

result = Book.objects.aggregate(Max('price'))
print(result)
# 输出：{'price__max': 100.0}
```

## 5. `Min`：求最小值

求所有图书中最低的价格：

```python
from django.db.models import Min

result = Book.objects.aggregate(Min('price'))
print(result)
# 输出：{'price__min': 10.0}
```

## 6. `Sum`：求和

求所有图书价格的总和：

```python
from django.db.models import Sum

result = Book.objects.aggregate(Sum('price'))
print(result)
# 输出：{'price__sum': 500.0}
```

## 7. 同时使用多个聚合函数

`aggregate` 可以同时使用多个聚合函数，一次性返回多个结果：

```python
from django.db.models import Avg, Max, Min, Sum, Count

result = Book.objects.aggregate(
    avg_price=Avg('price'),
    max_price=Max('price'),
    min_price=Min('price'),
    total_price=Sum('price'),
    book_count=Count('id')
)
print(result)
# 输出：{'avg_price': 50.0, 'max_price': 100.0, 'min_price': 10.0, 'total_price': 500.0, 'book_count': 10}
```

## 8. `annotate`：为每行添加聚合结果

比如统计每个作者的图书数量：

```python
from django.db.models import Count

authors = Author.objects.annotate(book_count=Count('book'))
for author in authors:
    print(author.name, author.book_count)
```

这里 `book_count` 就是每个作者关联的图书数量，作为 `Author` 实例的属性直接访问。

## 9. 配合 `values` 使用

`annotate` 经常和 `values` 一起用，实现分组统计：

```python
from django.db.models import Count, Avg

# 按出版社分组，统计每个出版社的图书数量和平均价格
result = Book.objects.values('publisher__name').annotate(
    book_count=Count('id'),
    avg_price=Avg('price')
)
for item in result:
    print(item['publisher__name'], item['book_count'], item['avg_price'])
```

这里 `values('publisher__name')` 相当于 SQL 里的 `GROUP BY publisher__name`，然后 `annotate` 里的聚合函数就相当于对每组做统计。

## 10. 常用的聚合函数一览

| 函数 | 说明 |
|------|------|
| `Avg` | 求平均值 |
| `Count` | 求数量 |
| `Max` | 求最大值 |
| `Min` | 求最小值 |
| `Sum` | 求和 |
| `StdDev` | 求标准差 |
| `Variance` | 求方差 |

这些函数都定义在 `django.db.models` 中，使用前记得导入。

## 11. 总结

*   `aggregate`：对**整个 QuerySet** 做汇总，返回一个字典。
*   `annotate`：对 **QuerySet 中每一行** 添加聚合结果，常配合 `values` 做分组统计。
*   常用的聚合函数有：`Avg`、`Count`、`Max`、`Min`、`Sum`。
*   可以给聚合结果起别名，方便读取。
*   分组统计的经典写法：`values(...).annotate(...)`。
