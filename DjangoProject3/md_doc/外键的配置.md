# 一、外键：

在 MySQL 中，表有两种引擎，一种是 InnoDB，另外一种是 myisam。如果使用的是 InnoDB 引擎，是支持外键约束的。外键的存在使得 ORM 框架在处理表关系的时候异常的强大。因此这里我们首先来介绍下外键在 Django 中的使用。

类定义为 `class ForeignKey(to,on_delete,**options)`。第一个参数是引用的是哪个模型，第二个参数是在使用外键引用的模型数据被删除了，这个字段该如何处理，比如有 `CASCADE`、`SET_NULL` 等。这里以一个实际案例来说明。比如有一个 `User` 和一个 `Article` 两个模型。一个 `User` 可以发表多篇文章，一个 `Article` 只能有一个 `Author`，并且通过外键进行引用。那么相关的示例代码如下：

```python
class User(models.Model):
    username = models.CharField(max_length=20)
    password = models.CharField(max_length=100)


class Article(models.Model):
    title = models.CharField(max_length=100)
    content = models.TextField()

    # author_id foreign key(user.id)
    author = models.ForeignKey("User", on_delete=models.CASCADE)
```

以上使用 `ForeignKey` 来定义模型之间的关系。即在 `article` 的实例中可以通过 `author` 属性来操作对应的 `User` 模型。这样使用起来非常的方便。示例代码如下：

```python
# 获取某篇文章的作者
article = Article.objects.first()
print(article.author.username)

# 获取某个用户的所有文章
user = User.objects.first()
articles = user.article_set.all()   # 默认反向查询名为 模型名小写_set
```

## 二、ForeignKey 常用参数

### 1. `to`

必填参数，指定要关联的模型。可以传模型类本身，也可以传模型名的字符串（用于解决循环引用问题）。

```python
# 直接传模型类
author = models.ForeignKey(User, on_delete=models.CASCADE)

# 传字符串
author = models.ForeignKey("User", on_delete=models.CASCADE)
```

### 2. `on_delete`

必填参数，指定当被引用的模型数据被删除时，当前字段该如何处理。常用取值如下：

| 取值 | 说明 |
|------|------|
| `models.CASCADE` | 级联删除，作者删除后，其所有文章也一并删除 |
| `models.PROTECT` | 保护模式，如果还有文章引用该作者，禁止删除作者，会抛 `ProtectedError` |
| `models.SET_NULL` | 设为 NULL，需要该字段 `null=True` |
| `models.SET_DEFAULT` | 设为默认值，需要该字段设置 `default` |
| `models.SET(...)` | 设为指定值，可以传一个函数或值 |
| `models.DO_NOTHING` | 什么都不做，数据库层面可能报错 |

```python
# 作者被删除后，文章也删除
author = models.ForeignKey(User, on_delete=models.CASCADE)

# 作者被删除后，文章的 author 字段设为 NULL
author = models.ForeignKey(User, on_delete=models.SET_NULL, null=True)

# 作者被删除后，文章的 author 字段设为默认用户
author = models.ForeignKey(User, on_delete=models.SET_DEFAULT, default=1)
```

### 3. `related_name`

用于设置反向查询的名称。默认是 `模型名小写_set`，通过 `related_name` 可以自定义。

```python
class Article(models.Model):
    author = models.ForeignKey(User, on_delete=models.CASCADE, related_name="articles")
```

设置后就可以这样反向查询：

```python
user = User.objects.first()
articles = user.articles.all()   # 不再用 article_set
```

### 4. `related_query_name`

用于反向查询时过滤器的名称，默认和 `related_name` 相同。如果不设置 `related_name`，默认是模型名。

```python
author = models.ForeignKey(User, on_delete=models.CASCADE, related_query_name="article")
```

### 5. `null` 和 `blank`

- `null=True`：数据库层面允许为 NULL。
- `blank=True`：表单验证时允许为空。

一般外键若允许为空，两者都要设置：

```python
author = models.ForeignKey(User, on_delete=models.SET_NULL, null=True, blank=True)
```

### 6. `db_column`

自定义数据库中的字段名，默认是 `字段名_id`。

```python
author = models.ForeignKey(User, on_delete=models.CASCADE, db_column="author_id")
```

## 三、外键的查询操作

### 1. 正向查询（从 Article 查 User）

```python
article = Article.objects.get(id=1)
print(article.author.username)   # 直接通过属性访问
```

### 2. 反向查询（从 User 查 Article）

```python
user = User.objects.get(id=1)

# 默认方式
articles = user.article_set.all()

# 自定义 related_name 后
articles = user.articles.all()
```

### 3. 通过外键过滤

```python
# 查询用户名为 "张三" 的所有文章
articles = Article.objects.filter(author__username="张三")

# 反向：查询写过分数为 100 的文章的用户
users = User.objects.filter(article__title="Hello")
```

## 四、多对多关系

除了 `ForeignKey`，Django 还提供 `ManyToManyField` 表示多对多关系。示例代码如下：

```python
class Article(models.Model):
    title = models.CharField(max_length=100)
    tags = models.ManyToManyField("Tag")


class Tag(models.Model):
    name = models.CharField(max_length=50)
```

操作方式：

```python
# 添加标签
article = Article.objects.get(id=1)
tag = Tag.objects.get(id=1)
article.tags.add(tag)

# 移除标签
article.tags.remove(tag)

# 查询所有标签
article.tags.all()
```

Django 会自动创建一张中间表来维护多对多关系，一般不需要手动定义。如果中间表还需要额外的字段，则需要用 `through` 参数指定自定义中间模型。

## 五、一对一关系

用 `OneToOneField` 表示一对一关系，例如用户和用户资料：

```python
class User(models.Model):
    username = models.CharField(max_length=20)


class UserProfile(models.Model):
    user = models.OneToOneField(User, on_delete=models.CASCADE)
    phone = models.CharField(max_length=20)
```

操作方式：

```python
user = User.objects.get(id=1)
profile = user.userprofile     # 反向访问
print(profile.phone)
```

---

## 六、总结

| 关系 | 字段类型 | 使用场景 |
|------|----------|----------|
| 一对多 | `ForeignKey` | 一篇文章对应一个作者，一个作者对应多篇文章 |
| 多对多 | `ManyToManyField` | 一篇文章有多个标签，一个标签属于多篇文章 |
| 一对一 | `OneToOneField` | 用户和用户资料，拆表存储 |

外键常用参数：

- `to`：关联的模型。
- `on_delete`：被引用数据删除时的处理方式，常用 `CASCADE`、`SET_NULL`、`PROTECT`。
- `related_name`：反向查询的名称。
- `null` / `blank`：是否允许为空。
- `db_column`：数据库字段名。
